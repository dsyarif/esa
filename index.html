ESA

E-Kinerja Screenshot Assistant

Tempel, upload, atau ambil screenshot — otomatis dinamai per tanggal, dilengkapi jam kegiatan dan judul, lalu dikompres di bawah 500 KB. Semua diproses langsung di browser kamu, tidak diunggah ke server mana pun.

1Tanggal Kegiatan
—

Nomor ini otomatis dihitung dari nomor tertinggi yang sudah ada di folder unduhan + sesi berjalan untuk tanggal ini — jadi tetap aman meski ada kegiatan yang belum sempat di-screenshot (misal 25.1 masih kosong tapi 25.2 sudah ada). Nomor tiap item tetap bisa kamu ubah manual di kartu masing-masing.

2Lokasi Unduhan
Belum diatur — unduhan akan memakai folder default browser (biasanya langsung tanpa dialog)

Sekali diatur, folder ini diingat otomatis walau halaman di-refresh atau ditutup — tidak perlu pilih ulang tiap kali buka ESA. Fitur ini hanya didukung Chrome/Edge; di browser lain file tetap terunduh ke folder Downloads default.

3Ambil Bukti
Tekan Ctrl+V di mana saja pada halaman ini untuk menempel screenshot dari clipboard — atau seret file gambar ke sini.

Catatan: "Ambil dari Layar" memakai izin berbagi layar browser — di beberapa tempat preview mungkin dibatasi. Kalau gagal atau ditolak, gunakan Tempel (Ctrl+V) atau Upload sebagai cara paling stabil.
